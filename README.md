# 🎄 Christmas Tree Joe (`christmastreejoe.com`)

Welcome to the official repository for **Christmas Tree Joe**, the premier sustainable Christmas tree subscription platform operated by **Xmas Made Inc.** (a **Global Citizen Joe, Inc.** company).

## 🚀 Key Features

- **Interactive 3D Tree Studio:** 360° interactive renders for Evergreen Sprout (4–5 ft), Holiday Hearth (6–7 ft), and Yuletide Monarch (8–9 ft) trees across Fraser, Douglas, and Noble Fir species.
- **Flexible Subscription Engine:** 1-to-10+ year custom subscription lock-ins with automatic multi-year discounts.
- **White-Glove Delivery & Pickup:** Automated scheduling for doorstep delivery and post-holiday tree collection.
- **100% Circular Economy:** Every tree collected is recycled into everyday products (mulch, compost, essential oils, and firewood).
- **Dual-Hub Vendor Network:** Direct integration with North Carolina tree farmers (`christmastreejoe.net`) for seamless last-mile fulfillment across Philadelphia and North Carolina.

## 🛠️ Tech Stack

- **Frontend:** React / Vite, Tailwind CSS, Three.js (WebGL 3D Rendering)
- **Backend / API:** Base44 Client SDK / Node.js
- **Payment Processing:** Credit/Debit Cards, PayPal, Square, Apple Pay, Google Pay, Cryptocurrency
- **Deployment:** PWA-ready for iOS Safari and Android Chrome, Capacitor wrapper for App Store deployment.
